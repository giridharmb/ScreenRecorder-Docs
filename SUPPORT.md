# Get help

[← Screen Recorder](README.md) · [Troubleshooting](guides/troubleshooting.md) · [Release status](RELEASES.md)

The app is preparing for public release, and this documentation describes a preview. If you have a preview build, include its version when asking for help.

## Ask a question or report a problem

Check [existing issues](https://github.com/giridharmb/ScreenRecorder-Docs/issues) first. If the problem is new, [open an issue](https://github.com/giridharmb/ScreenRecorder-Docs/issues/new/choose) with:

- Your Screen Recorder version and macOS version.
- Whether your Mac uses Apple silicon or Intel, and whether another display or audio device was connected.
- The capture mode, audio switches, format, and relevant settings.
- Short steps to reproduce the problem, what you expected, and what happened.
- The error message, with personal information removed.

A small example using a blank document or fictional browser page is useful. Do not attach private recordings, screenshots of personal windows, passwords, or unredacted crash reports. GitHub issues are public. A support response time is not guaranteed during the preview.

## Request a feature

Open an issue describing what you want to accomplish and where the current workflow gets in the way. Explain the outcome you need; there is no need to propose an implementation.

## Installation or download concerns

There is no public download yet. Check [release status](RELEASES.md) before installing a copy advertised elsewhere. Do not bypass macOS security warnings to install it. Report a suspicious link or an unexpected installation message without including credentials or private information.
